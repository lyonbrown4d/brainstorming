# Tauri 测试迁移记录

2026-10-26：桌面已迁移至 Tauri 3 alpha / CEF，WDIO 已通过官方 ChromeDriver 恢复。当前 Linux CEF 验证与 GPU 隔离测试入口见 [CEF 迁移记录](cef-migration.md)。下文较早的系统 WebView 记录保留为历史，不作为 CEF 的帧率或跨平台验收证据。

## 保留的 TypeScript 与原生 UI 测试

纯 TS 的 core、layout、编辑器、共享文件安全、恢复状态、XMind、Markdown、OPML、SVG、archive、assets、AI apply、MCP workspace 和组件测试继续运行。原来混合使用 Node 原生编码器的 XMind、结构、内容、创建和调色板测试，保留导入 / 状态断言，使用 core serialize / deserialize 验证可移植模型；真实文件持久化由 Rust 测试负责。

测试 fixture 通过 `installPlatformAPI` 安装平台对象，并在每个测试结束后恢复，匹配 Tauri 的显式初始化。不存在用 `window.brainstorming` 注入生产后端的回退。

[tests/native](../tests/native) 定义六个真实 Tauri WDIO 流程：启动交接、中文编辑与撤销重做及保存重开、独立画布和多文档、2D / 3D 编辑、资源持久化与导出、加密与取消及错误密码重试。测试定义不等于所有宿主和设备已执行；运行结果以本次任务报告为准。旧 Electron Playwright UI / 性能 / 打包测试由原生 UI 测试迁移单独处理。

## 本次已执行的验证

- Rust 文档回归在当前最新依赖下通过 18 项：roundtrip 5、resources 2、security 3、metadata 1、shutdown 1、validation 4、capacity 2。
- 保留的格式、assets、创建、调色板、文件安全、恢复状态、平台边界、导出、AI apply、MCP workspace 共 15 个 Vitest 文件，129 项通过。
- 本页不将 iOS / Android 编译、签名、真机媒体 / 剪贴板或系统安全存储列为已通过；这些必须在目标平台执行。
