# macOS 交互验收

2026-11-01。本轮从 `d14aff6` 基线迭代，范围为依赖升级与已确认的七项 P1/P2 交互改进。运行环境为 macOS 27.2、Apple M1 Pro、arm64、DPR 2；使用 Node 25.2.1、pnpm 12.16.1 和 Rust 1.99.1。

本轮自动化回归、macOS 完整 CEF 交互验收及发布包构建检查已通过。发布包额外的界面读取检查超时，未确认发布界面；用户随后明确要求停止继续实机检查并提交、推送，该项保留为未验证。

完整原生回归另发现 macOS 窗口缩放或原生标题变化后 CEF 重置窗口按钮位置。用户已明确批准通过官方接口临时恢复配置；问题证据、上游草稿和移除条件见 [窗口按钮位置记录](cef-window-buttons.md)。包含该适配的完整应用已通过最终原生回归。

## 变更范围

| 交互         | 验收重点                                                           |
| ------------ | ------------------------------------------------------------------ |
| 主题宽度     | 二维、三维左右手柄；换行而非缩放文字；取消恢复；一次撤销；保存重开 |
| 大纲工作区   | 虚拟列表、中文编辑、键盘新增及缩进、子树拖动、取消、撤销与保存     |
| 画布筛选     | 保留匹配主题及祖先；隐藏选区处理；退出恢复；不改变正文、历史和导出 |
| 就近新增     | 单选主题旁新增子主题或同级主题；根主题限制；避免遮挡邻居           |
| 浮动栏固定   | 文档栏与操作栏独立固定、持久保存；收起入口仍可发现                 |
| 快速空白文档 | 等待路由、原生命令和首帧就绪；首次编辑焦点；中文标题与保存         |
| 样式复制     | 所选、同层、后代范围；等待原生命令确认；保持位置与深度；一次撤销   |

实现继续复用 React Flow、CameraControls、Lexical、TanStack Virtual、dnd-kit、Radix / shadcn 与既有 Rust 命令。三维与二维共享业务命令和历史。

回归中另修正了 CEF 内部占位页过早触发原生服务初始化的问题：仅可信主页面完成加载后触发初始化，启动文件在成功后领取一次，重载不会重复打开。窗口专项已覆盖启动、外观切换、双向缩放、文档创建及全屏退出。

同时修正了原生命令确认前切换工作区导致的编辑、样式竞态，大纲滚动后编辑行卸载，以及三维静止点击结束后控件仍隐藏的问题。后者增加了真实按下、松开指针的画布回归，先确认旧实现失败，再验证修复通过。

原生验收使用独立 `app.brainstorming.e2e` 标识、当前源码与静态前端构建的完整应用。CEF 为 154.0.8037.98，官方 ChromeDriver 为 154.0.8037.92；构建版本前缀匹配。各测试文件独立进程，不连接开发 renderer，不通过强制点击绕过加载门禁。

发布模式仅在隔离的 E2E 构建中开放调试接口，普通发布包未开放该测试入口；额外 ChromeDriver 检查未建立连接，不能据此判定发布界面失败或通过。桌面辅助工具读取发布界面同样超时，未继续重试或修改用户缓存。

## 依赖与边界

前端升级 12 项兼容依赖，Cargo 更新 6 项兼容依赖；锁文件随提交保留。Tauri、Specta 和 FluxDI 的固定版本保持不变。未为消除开发依赖告警强行覆盖不兼容的大版本。

审计剩余 3 项中等级开发依赖告警，无高等级或严重告警，分别来自 [got](https://github.com/advisories/GHSA-pfrx-2q88-qq97)、[minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249) 和 [glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) 的上游依赖链。代码检查有两项 TanStack Virtual / React Compiler 兼容性警告，分别位于大纲和演示虚拟列表；Compiler 对这两处跳过自动记忆化，相关交互继续由真实输入回归验证。

三维调整宽度时，GPU 连线在提交后更新；密集布局没有安全放置位置时，就近新增入口收起，仍可通过底部操作栏新增。本轮只验收 macOS；Windows、Linux、移动端不据此宣告通过。发布包采用本机临时签名，不代表 Developer ID 签名或公证完成；Quick Look 扩展的打包、签名检查也不替代 Finder 内实际预览验收。
