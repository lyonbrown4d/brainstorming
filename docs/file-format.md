# Trelyx 原生格式与格式转换

## 工作簿与多画布

一个 `.trelyx` 文件是一份工作簿，包含有序的 `sheets`，不是只保存当前画布。工作簿、Sheet、文档、主题和资源分别使用稳定 ID。文件标题、画布名称和中心主题标题相互独立。

每个 Sheet 保存自己的主题树、样式、备注和资源引用。相同资源 ID 或同名附件在不同 Sheet 中隔离。复制画布保留全部内容，之后可独立编辑；删除后撤销恢复原内容。选择、活动画布、视口、撤销历史和输入草稿不进入正式文件，重新打开默认选择第一张画布。

## 原生容器

扩展名为 `.trelyx`，MIME 为 `application/vnd.trelyx+zip`。容器使用 ZIP，必需条目为 UTF-8 编码的 `manifest.json` 和 `document.json`；图片及附件按需嵌入：

```text
example.trelyx
├── manifest.json
├── document.json
└── assets/
    ├── 0/photo-id
    ├── 0/attachment-id
    └── 1/photo-id
```

清单的 `format` 为 `app.trelyx.document`、`version` 为 `1`，`createdBy` 记录应用名称和版本。协议版本与应用版本分别维护。

`document.json` 包含以下字段：

```text
{
  id, title,
  sheets: [{
    id, name,
    document: {
      id, title, rootId,
      topics: { [topicId]: Topic },
      assets?: { [assetId]: { id, name, mimeType, path } }
    }
  }]
}
```

`Topic` 包含 `id`、纯文本 `title`、有序 `children`、`collapsed`、`side`、可选 `style`、`metadata`、`structure`、`notes`、`image: { assetId, width, height }` 和 `attachments: assetId[]`。图片宽高记录资源尺寸，画布显示尺寸由布局计算。一个主题支持一张图片和最多 32 个附件，备注最多 100000 字符。

包内资源路径为 `assets/<sheet-index>/<asset-id>`，与原始磁盘路径无关。画布排序后重新生成路径，ID 和引用不变。同一页多个引用只写一份资源；复制页在对应分组保存资源。工作簿全部资源合计受统一大小限制。

资源元数据和字节必须一致，引用必须存在。写出仅保留被主题引用的资源；移除后的字节留在会话快照中供撤销，不写入正式文件。读取拒绝未知字段、未引用资源、缺失字节、错误路径和尺寸不符，避免静默丢失。预览图尚未提供。早期无资源的 ZIP v1 文件仍可读取；此前 JSON `.trelyx`、`.json` 和旧 JSON 恢复文件不迁移。

主题 metadata 保存标签、图标、网页/内部主题链接、任务、公式、音频资源 ID、备注格式和可移植 Markdown 标题。富文本不持久化 Lexical 内部节点。Document 可保存 `settings`、`relations`、`groups`、`callouts`、`floatingIds`、`floatingPositions` 和 `presentation`。游离主题仍使用树的稳定 ID 和唯一父级规则，其根附件关系不渲染为连线；显式位置是文档数据。普通视口不持久化，主动保存的演示步骤可包含三维相机。

音频使用同一资源路径与预算。导入通过字节嗅探校验支持的音频类型，不能只凭扩展名认定类型。

内部 core JSON 使用规范 base64 传输资源字节，仅用于 IPC、状态比较及浏览器恢复；磁盘 ZIP 使用原始二进制，不写 Lexical 内部状态或 React Flow 节点。

## XMind 打开行为

存在 `content.json` 时使用现代格式，否则读取旧版 `content.xml`，配合 `styles.xml` 解析样式引用。现代内容损坏时不回退到可能过期的 XML。

导入生成可编辑、未保存的 Trelyx 工作簿；首次保存选择 `.trelyx` 文件，主进程不允许向 `.xmind` 路径保存。最近文件保留源文件入口，重新打开会重新导入。

| 内容                             | 当前支持                                           |
| -------------------------------- | -------------------------------------------------- |
| 多画布、名称和顺序               | 保留，长名称调整并提示                             |
| 主题标题、中文、多行、层级和顺序 | 保留                                               |
| 折叠与基础样式                   | 保留折叠，映射支持范围内的颜色、字号、粗斜体和形状 |
| 备注                             | 保留纯文本；富文本转换为纯文本并提示格式未保留     |
| 包内 PNG/JPEG/GIF/WebP           | 嵌入为主题图片，保留资源字节                       |
| 指向包内资源的附件链接           | 嵌入并提供另存                                     |
| 游离、概要等附加主题             | 转为命名分支，提示原位置或语义变化                 |
| 标签和安全网页链接               | 保留；导入不会访问链接                             |
| 第三方关联线、概要关系、图标等   | 未映射内容在导入报告中聚合提示                     |
| XMind 导出                       | 现代 ZIP；额外字段放入 Trelyx 命名空间扩展         |

不请求网络或任意本地路径，不执行备注中的 HTML。缺失、重复和保留名称的 ID 会重新生成；损坏、缺失、超限和不支持的内嵌资源会跳过并提示。不承诺视觉完全一致或无损往返。

## 边界与恢复

- 压缩文件最大 32 MiB，最多 512 个 ZIP 条目，单条目解压后最大 10 MiB，累计最大 64 MiB。
- 单资源最大 8 MiB，整份工作簿引用资源最大 24 MiB。复制页超出资源预算时操作失败并保留原内容。
- 图片单边最多 8192 像素，总计最多 4000 万像素；SVG/HTML 不作为图片显示。附件通过显式另存导出，不自动执行。
- 支持 ZIP stored/deflate；普通解码拒绝加密；专用解锁流程仅支持 AES-256 原生文件。拒绝分卷、ZIP64、重复名称和路径穿越；校验 CRC、目录与实际解压大小，不解压到磁盘。
- 工作簿最多 128 个画布、20000 个主题；中心主题计为第一层，最多 128 层。
- XML 拒绝 DOCTYPE 和自定义实体，预定义转义正常读取。
- 完整解析校验通过后才替换当前文档。读取期间新增修改需要再次确认，保存失败保留未保存状态。
- 桌面恢复文件 `userData/recovery-v1.trelyx` 采用同一二进制协议，覆盖所有画布与资源并原子写入。浏览器使用 idb-keyval/IndexedDB，避免资源超出 localStorage 容量。恢复损坏不覆盖原记录。

测试包含现代/旧版 XMind、官方 MIT 样例、内嵌图片与二进制附件，以及多 Sheet 的内容编辑、复制、排序、删除撤销和原生保存重开。实际系统文件关联注册仍需安装打包产物后按平台检查。

## XMind 导出与大纲交换

XMind 导出包含标准主题、基础样式、折叠、图片、备注、首个附件/安全链接和标签。Trelyx 专有元数据、多附件、音频、方向、混合结构、布局、注解、游离位置和演示步骤保存在 `org.trelyx.interchange` 扩展；Trelyx 重新导入时严格校验并恢复。其他应用可能忽略这些扩展，不承诺在 XMind 中呈现全部语义。第三方扩展不会被当成 Trelyx 内容执行。

Markdown/OPML 导入先预览再替换当前工作簿。OPML 禁用 DTD 和自定义实体。Markdown、OPML、文本导出为大纲，会损失图像、复杂样式和部分元数据；界面在导出前说明。当前 Sheet 输出会移除指向未导出 Sheet 的内部链接。

PNG/SVG/PDF 从完整二维布局生成，可选择展开所有折叠分支；不截取当前 DOM。PNG/PDF 受单边 16384 像素和 4000 万像素预算限制，超出时提示降低倍率或使用矢量图。打印复用完整 SVG、隔离 iframe 与系统打印。

## 密码与本地历史

密码文件使用 `@zip.js/zip.js` 的 AES-256 ZIP：清单、正文和资源条目全部加密。解锁流程校验压缩与解压预算、路径、重复条目、认证码及原生模型。文件名和 ZIP 目录元信息不隐藏。忘记密码无法恢复。

桌面密码仅保留在主进程会话中；解锁使用限时不透明 token，取消或读取期间新增修改不能提前替换当前密钥。浏览器预览的密码仅保留在 renderer 内存。自动恢复按相同密码加密；启用密码时同步保护已有明文恢复记录与本工作簿明文快照。修改密码后旧加密快照保留创建时的密码。普通导出副本不带原生密码保护。

成功保存后，本机 `userData/history-v1` 保留最近 20 份快照，按工作簿 ID 分组浏览，磁盘总量有统一数量上限。UI 仅传递严格格式的版本 ID，不接受任意文件路径；恢复前确认当前修改，恢复结果需再次保存才更新正式文件。历史文件不随文档复制到其他电脑。浏览器预览不提供该目录型历史功能。
