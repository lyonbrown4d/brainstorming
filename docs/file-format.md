# Trelyx 原生格式与 XMind 导入

## 原生文件

扩展名为 `.trelyx`，MIME 为 `application/vnd.trelyx+zip`，采用 ZIP 容器。必需条目为 `manifest.json` 和 `document.json`，JSON 使用 UTF-8。应用版本和协议版本分别维护。

```json
{
  "format": "app.trelyx.document",
  "version": 1,
  "createdBy": { "name": "Trelyx", "version": "0.1.0" }
}
```

`document.json` 结构如下；示例中的省略号仅用于说明，不是合法文件内容：

```text
{
  id, title,
  sheets: [{
    id, name,
    document: { id, title, rootId, topics: { [topicId]: Topic } }
  }]
}
```

`Topic` 包含 `id`、纯文本 `title`、有序 `children`、`collapsed`、`side` 和可选 `style`。样式字段为填充、文字颜色、字号、粗体、斜体、形状、线型和线宽。工作簿标题、画布名称和中心主题标题独立保存。文件不保存 Lexical 内部状态、React Flow 节点、选择、视口、历史和输入草稿。

`assets/` 与预览能力留待后续协议定义；当前版本不写入图片或附件。非空附件、预览和未知原生内容会明确拒绝，避免读取后保存时丢失。空 `assets/` 目录允许存在。未来协议版本明确拒绝。

这是全新的原生协议，不读取此前以 JSON 保存的 `.trelyx` 或 `.json`，不自动迁移旧单画布、多画布文件及旧恢复记录。应用内部用于 IPC 和状态比较的 core JSON 与容器协议分开。

## XMind 打开行为

选择 `.xmind` 后读取压缩包。存在 `content.json` 时使用现代格式；否则读取旧版 `content.xml`，可配合 `styles.xml` 解析样式引用。如果现代内容损坏，不回退到可能过期的 XML。

导入结果是可编辑、未保存的 Trelyx 工作簿。首次保存必须选择 `.trelyx` 文件；主进程禁止授权或写入 `.xmind` 保存路径。源文件可出现在最近文件中，重新打开会重新导入。

| 内容                                       | 当前支持                                   |
| ------------------------------------------ | ------------------------------------------ |
| 多画布、名称和顺序                         | 保留，长画布名称调整并提示                 |
| 主题标题、中文、多行、层级和顺序           | 保留                                       |
| 折叠状态                                   | 保留                                       |
| 显式颜色、字号、粗斜体、常用形状           | 映射到 Trelyx 支持范围                     |
| 原始布局与坐标                             | 重新计算为 Trelyx 左右布局，并提示         |
| 游离主题等附加主题                         | 转为命名分支，保留文本和子树，提示语义变化 |
| 图片、备注、附件、关联线、概要关系、图标等 | 不支持的字段在导入报告中聚合提示           |
| XMind 导出                                 | 尚不支持                                   |

不承诺视觉完全一致或无损往返。缺失、重复和保留名称的 ID 会重新生成，并显示提示。导入成功后可通过顶部“查看导入报告”了解调整。原生文件中的未知字段采用拒绝策略；第三方导入采用明确报告策略。

## 边界与恢复

- 压缩文件最大 20 MiB，最多 512 个 ZIP 条目，单条目解压后最大 10 MiB，累计最大 40 MiB。
- 支持 ZIP stored/deflate；不支持加密、分卷及 ZIP64。
- 校验 CRC、目录一致性和实际解压大小；拒绝重复名称、绝对路径和路径穿越，不解压到磁盘。
- 工作簿最多 128 个画布、20,000 个主题；中心主题计为第一层，最多 128 层。
- XML 拒绝 DOCTYPE 和自定义实体声明；预定义转义字符正常读取。
- 完整解析和校验通过后才替换当前文档，读取期间的新增修改需要再次确认。
- 桌面保存和自动恢复使用原子写入；恢复文件为 `userData/recovery-v1.trelyx`，与旧恢复记录隔离。浏览器恢复使用独立 localStorage 命名空间。

## 验证样例

`tests/fixtures/xmind` 包含手工编写的现代 JSON、旧版 XML 和样式数据，运行测试时使用 ZIP 库封装；另含固定版本的官方嵌入查看器样例和许可证，来源见该目录说明。样例覆盖中文、多行、多画布、折叠、样式引用、附加主题和不支持内容。

浏览器 E2E 验证两类 XMind 的导入、报告、编辑、原生保存和重新打开；桌面测试验证二进制文件、恢复、启动路径、系统事件与源文件保护。操作系统文件关联的注册效果仍需在安装打包产物后按平台检查。
