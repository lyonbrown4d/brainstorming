# 本地能力交付清单

本轮补齐已讨论的桌面常用能力，保留 Trelyx 的 2D/3D、本地文件和多 Sheet 方向。多人协作、评论和分享链接不在本次范围。

## 已实现

| 能力         | 操作与边界                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| 浮动 Dock    | 默认收起，hover、点击或键盘聚焦展开，离开延迟收起；连线、编辑和子面板期间保持展开，触屏可点击切换    |
| 直接画布操作 | 二维/三维点击主题起终点建立关联，边界与概要使用选区，注解原位编辑；游离主题点击画布放置              |
| 批量编辑     | 多选、框选、批量样式、移动和删除；子树剪贴板、剪切、副本、跨 Sheet 资源复制，一次撤销                |
| 查找与筛选   | 跨 Sheet 标题/备注查找、定位与当前 Sheet 替换；标签、图标、任务筛选定位                              |
| 结构与外观   | 8 种布局、分支混合结构、全局主题/字体/背景/线宽、复制主题样式，4 种可编辑模板                        |
| 主题内容     | Lexical 局部标题格式、Markdown 富文本备注、标签、图标、网页/主题链接、任务、公式、音频导入播放和录音 |
| 大纲与演示   | 独立大纲编辑、主题步骤排序、显式保存三维视角；播放临时展开祖先，不改变折叠历史                       |
| 格式交换     | Markdown/OPML 导入，PNG/SVG/PDF/Markdown/OPML/文本/XMind 导出，完整二维导图打印                      |
| 文件安全     | AES-256 原生文件、加密自动恢复、开启密码时保护旧明文历史；本机最近 20 份快照与恢复                   |
| AI           | 自配兼容服务与密钥，生成新画布、扩写、整理副本，明确发送、预览后应用、取消和异步变化保护             |

画布工具入口统一在 Dock，通用控件复用官方 shadcn/Radix；业务差异通过组合和 Tailwind。布局复用 d3-hierarchy/Dagre，富文本复用 Lexical，公式复用 KaTeX，文件加密复用 zip.js，输出复用成熟格式库与 jsPDF，AI 复用 AI SDK。

## 验证

2026-10-16 在当前 macOS 环境完成：

- 格式、ESLint、TypeScript 检查通过；手写源码未超过 300 行。
- 46 个单元测试文件、389 项测试通过。
- 29 项浏览器 E2E 与 3 组固定 100/1000/5000 主题采样通过；每组采样三次，无硬性性能阈值。
- 6 项真实 Electron 回归通过，涵盖窗口/preload、资源保存、系统打开、原生剪贴板、离线 AI、加密文件/恢复/历史。
- 41 项 Storybook 浏览器交互通过；生产构建和 Storybook 静态构建通过。
- 生产依赖审计未发现已知漏洞。

回归同时修复了默认边端口、主题重复选中提交草稿、Ctrl+A 被全图选择截获，以及双击被画布平移捕获的问题。跨工作簿粘贴移除无法解析的跨 Sheet 链接并提示，保留其他内容与资源。

## 实际限制

- XMind 第三方扩展和部分原生注解/结构仍会转换或省略，不承诺无损往返或视觉一致；Trelyx 自有扩展可由 Trelyx 重新导入。
- 图形导出与打印使用完整二维布局；PDF 内文字为栅格，不能搜索。大纲格式有信息损失，导出前有说明。
- 旧加密快照使用创建时密码；导出副本不带原生密码。浏览器预览不提供本机目录型版本历史。
- AI 验证使用真实 SDK 与离线本机服务；未使用付费密钥验证第三方模型。录音已验证模拟设备生命周期，未测试实体麦克风硬件。
- Windows/Linux 原生行为、系统安装关联、macOS 正式签名/公证和安装后的麦克风权限尚需对应环境验证。
- 构建仍提示部分编辑器/三维包较大；Three.js/Chromium 有弃用或编辑布局提示。窄窗口切换偶见 ResizeObserver 延迟通知，功能回归通过，仍需后续观察。
