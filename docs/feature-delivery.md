# 本地能力交付清单

本轮补齐已讨论的桌面常用能力，保留 Brainstorming 的 2D/3D、本地文件和多 Sheet 方向。多人协作、评论和分享链接不在本次范围。

## 已实现

| 能力           | 操作与边界                                                                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 浮动 Dock      | 画布底部居中，工具单行平铺且可横向滚动；默认收起，hover、点击或键盘聚焦展开，离开延迟收起；连线、编辑和子面板期间保持展开，触屏可点击切换       |
| 启动画面       | Electron 独立无边框窗口，主界面首帧就绪后切换；加载失败或耗时较长可重试，启动期间可退出；Vite 双 HTML 入口统一构建                              |
| 创建引导       | 启动首页、新建文档和新增 Sheet 选择结构、模板与名称；桌面最近文件、主动探索示例；取消保留当前文档，新增 Sheet 沿用保存路径                      |
| 连续编辑       | 单击选择、Space/双击续写、F2/直接输入替换；Enter 确认后再建同级；中文选区稳定，二维/三维共享布局导航及父主题、排序、折叠快捷键                  |
| 直接画布操作   | 二维/三维点击主题起终点建立关联，边界与概要使用选区，注解原位编辑和删除，选中关联线可拖端点改接；游离主题支持双击空白创建                       |
| 批量编辑       | 空白拖动平移、Shift 拖框多选、整组和子树拖动预览，结束一次提交；批量挂接、排序、游离组平移；子树剪贴板、剪切、副本、跨 Sheet 资源复制，一次撤销 |
| 三维选区与拖动 | Shift 双向完整卡片框选、修饰键追加选择、所选子树与连线预览；挂接/排序/游离组平移共用二维命令，一次撤销；取消或切换 Sheet 撤回预览               |
| 缩略图         | 复用 React Flow MiniMap，定位、平移、缩放；可关闭并重新打开，开关为本机偏好                                                                     |
| 图标与任务     | Dock 即时设置 P1–P3、完成及进度；常用图标和可搜索的离线 Simple Icons，共用二维/三维徽标及矢量导出                                               |
| 异步与恢复     | TanStack Query 共享最近文件 IPC 缓存；RxJS 合并与串行恢复写入，失败后可继续                                                                     |
| 查找与筛选     | 跨 Sheet 标题/备注查找、定位与当前 Sheet 替换；标签、图标、任务筛选定位                                                                         |
| 结构与外观     | 9 类结构、15 个方向选项，Dock 缩略图选择、分支混合结构、全局主题/字体/背景/线宽、复制主题样式，4 种可编辑模板                                   |
| 主题内容       | Lexical 局部标题格式、Markdown 富文本备注、标签、图标、网页/主题链接、任务、公式、音频导入播放和录音                                            |
| 大纲与演示     | 独立大纲编辑、主题步骤排序、显式保存三维视角；无步骤时自动生成临时路线，专注/可选全屏、键盘翻页和只读播放，退出恢复选择与二维/三维视图          |
| 格式交换       | Markdown/OPML 导入，PNG/SVG/PDF/Markdown/OPML/文本/XMind 导出，完整二维导图打印                                                                 |
| 文件安全       | AES-256 原生文件、加密自动恢复、开启密码时保护旧明文历史；本机最近 20 份快照与恢复                                                              |
| AI             | 自配兼容服务与密钥，生成新画布、扩写、整理副本，明确发送、预览后应用、取消和异步变化保护                                                        |

画布工具入口统一在 Dock，通用控件复用官方 shadcn/Radix；业务差异通过组合和 Tailwind。布局复用 d3-hierarchy 的树形与分区算法，富文本复用 Lexical，公式复用 KaTeX，文件加密复用 zip.js，输出复用成熟格式库与 jsPDF，AI 复用 AI SDK。

## 验证

2026-10-16 在当前 macOS 环境完成：

- 格式、ESLint、TypeScript 检查通过；手写源码未超过 300 行。
- 60 个单元测试文件、588 项测试通过，包含结构命令、布局导航、框选拖动、图标导出、演示恢复、异步缓存和恢复队列。
- 64 项浏览器 E2E 与 3 组固定 100/1000/5000 主题采样通过；每组采样三次，无硬性性能阈值。全部结构验证真实 WebGL 渲染，新增结构验证三维中文编辑与二维共享历史；创建引导覆盖取消、中文组词和独立 Sheet，已有触控板回归继续通过。启动回退覆盖慢加载、减少动态效果及失败重试。本轮补充二维/三维空白左键平移与 Shift 框选切换、三维整组挂接和游离组位置保存、指针取消与切换 Sheet 回滚、直接中文输入、原生文字选区删除、组拖动、关联线重连、缩略图偏好、离线图标和演示视口恢复。
- 9 项真实 Electron 回归通过，涵盖窗口/preload、资源保存、系统打开、原生剪贴板、离线 AI、加密文件/恢复/历史，以及首页创建、最近文件和保存路径沿用。原生菜单缩放验证画布比例与页面比例独立。原生启动窗验证主窗保持隐藏、故障重试、就绪交接、最小 preload 与提前退出。
- 51 项 Storybook 浏览器交互通过；双 HTML 入口生产构建和 Storybook 静态构建通过。WebGL 用例避免与其他浏览器测试并发运行，原生焦点用例显式激活测试应用。Vite、electron-vite 和 Storybook 显式预构建 React Three Fiber、Drei 与 Three.js SVGLoader，避免首次进入三维触发依赖重优化刷新或旧依赖 504。
- 生产依赖审计未发现已知漏洞。

回归还修复了原生文本激活时首字被重选、快速选区删除使用旧范围、演示退出被自动居中覆盖、Dock 按 Esc 后无法重新 hover 展开、缩略图关闭按钮遮挡及品牌图标导出溢出丢失。此前回归修复了默认边端口、主题重复选中提交草稿、编辑中 Ctrl+A 被全图选择截获，以及双击被画布平移捕获的问题。跨工作簿粘贴移除无法解析的跨 Sheet 链接并提示，保留其他内容与资源。

## 实际限制

- XMind 第三方扩展和部分原生注解/结构仍会转换或省略，不承诺无损往返或视觉一致；Brainstorming 自有扩展可由 Brainstorming 重新导入。
- 图形导出与打印使用完整二维布局；PDF 内文字为栅格，不能搜索。大纲格式有信息损失，导出前有说明。
- 旧加密快照使用创建时密码；导出副本不带原生密码。浏览器预览不提供本机目录型版本历史。
- AI 验证使用真实 SDK 与离线本机服务；未使用付费密钥验证第三方模型。录音已验证模拟设备生命周期，未测试实体麦克风硬件。
- Windows/Linux 原生行为、系统安装关联、macOS 正式签名/公证和安装后的麦克风权限尚需对应环境验证。
- 构建仍提示部分编辑器/三维包较大；离线 Simple Icons 数据约 4.75 MB，按需加载；Three.js/Chromium 有弃用或编辑布局提示。窄窗口切换偶见 ResizeObserver 延迟通知，功能回归通过，仍需后续观察。
