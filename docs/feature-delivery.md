# 本地能力交付清单

本页保留 2026-10-16 的交付与验收记录，包含当时的 ZIP/zip.js 实现。当前原生 SQLite、文件内版本与资源机制见 [文件协议](file-format.md)；下述历史结果不作为本次存储改造的验收结果。

本轮补齐已讨论的桌面常用能力，保留 Brainstorming 的 2D/3D、本地文件和多 Sheet 方向。多人协作、评论和分享链接不在本次范围。

## 实际限制

- XMind 第三方扩展和部分原生注解/结构仍会转换或省略，不承诺无损往返或视觉一致；Brainstorming 自有扩展可由 Brainstorming 重新导入。
- 图形导出与打印使用完整二维布局；PDF 内文字为栅格，不能搜索。大纲格式有信息损失，导出前有说明。
- 旧加密快照使用创建时密码；导出副本不带原生密码。浏览器预览不提供本机目录型版本历史。
- AI 验证使用真实 SDK 与离线本机服务；未使用付费密钥验证第三方模型。录音已验证模拟设备生命周期，未测试实体麦克风硬件。
- Windows/Linux 原生行为、系统安装关联、macOS 正式签名/公证和安装后的麦克风权限尚需对应环境验证。
- 构建仍提示部分编辑器/三维包较大；离线 Simple Icons 数据约 4.75 MB，按需加载；Three.js/Chromium 有弃用或编辑布局提示。窄窗口切换偶见 ResizeObserver 延迟通知，功能回归通过，仍需后续观察。

## 2026-10-17：SQLite 单文件与原生资源

本次原生格式改为 SQLite，不迁移旧 ZIP/JSON 文档、旧恢复记录或本机数据库。Kysely 统一管理文档和本机元数据库，迁移使用静态注册的显式 TypeScript 代码。Effect 官方 Pool 按规范文件路径和凭据复用连接，关闭标签与退出应用时释放资源。

资源以 SHA-256 去重、256 KiB 分块保存。主进程使用 Sharp/libvips 生成预览和多分辨率瓦片，renderer 通过受限协议读取图片与媒体；Range 请求只读取所需分块。图片放大查看复用 OpenSeadragon。文件拖入复用 Electron 的真实文件路径；网页预览由独立 Electron session 自动截图，p-queue 串行执行、去重并取消已移除的链接。

密码保护使用 SQLCipher；结构版本和二进制位于同一文件。补充首次写入失败重试、密码变更补偿、别名路径、损坏分块、有界读取、保存副本后移除源文件、资源撤销以及退出顺序的回归。历史恢复保留当前已解锁的密钥，附件导出使用 Node 流的 flush/close 后再替换目标文件。

验证记录：809 项单元和集成测试通过；格式、ESLint、TypeScript、生产构建与 Storybook 构建通过；生产依赖审计没有发现已知漏洞。102 项真实 Electron 交互用例首轮 101 项通过，演示退出视口断言出现一次波动；该演示用例随后连续两轮复测，二维和三维共 4 项通过。新资源专项验证真实图片瓦片、Range、原生拖放、删除源文件后重开与公共网页自动截图。本次没有运行大资源性能基准，不能据此声明吞吐或内存性能。

最终构建后的资源、密码、附件、多 Sheet、演示和打包启动复测通过 9 项；公共网页截图因网络预检未通过跳过，该能力已在前述完整回归中实际通过。macOS arm64 预览包能够从 ASAR 启动、使用隔离本机数据库、原生保存 SQLite 并正常退出；产物未签名或公证，尚未验证 Windows/Linux 安装行为。

Storybook 最终复测 18 个文件、62 项交互全部通过。`lodash-es` 与 OpenSeadragon 加入共享 Vite 预构建列表，避免首次加载新依赖时自动刷新开发或组件测试页面。
