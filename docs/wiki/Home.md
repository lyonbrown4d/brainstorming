# Trelyx 项目 Wiki

Trelyx 是本地优先的桌面思维导图应用，使用 React Flow、Electron、Vite、Moon、TypeScript 和 shadcn/ui。当前版本为 V0.1，项目采用单 package。

功能包含主题树编辑、左右自动布局、分支折叠与移动、大纲、撤销重做、本地文件和自动恢复。当前不接入云服务、数据库或账户，不兼容 `.xmind`。
