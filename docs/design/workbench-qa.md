## 发现、修复与复核

1. **P1，按钮样式覆盖，已修复。** 首轮实图中品牌字号、按钮颜色和 2D/3D 状态不符。旧的未分层 button 与 shadcn slot reset 覆盖了 Tailwind。将默认规则放入 base layer，删除针对基础组件的业务覆盖；最终顶栏对照显示正确的品牌层级、边框和选中态，官方组件源码保持不变。
2. **P2，三维颜色偏灰、内容偏小，已修复。** 首轮卡片受光照映射影响。卡片采用 Three.js 无光照材质保持主题色，保留真实几何、分支深度和投影；叶子加入淡分支色，调整取景留量。最终图中紫色中心与四色分支可区分，标题完整显示。
3. **P2，侧栏动画造成画布抖动，已修复。** 最初按宽度挤压画布，逐帧测试发现二维约 26px、三维约 42px 位移，并有 ResizeObserver 警告。改为覆盖式侧栏，渲染表面尺寸稳定；Dock、视角按钮及适应全图使用两栏之间的可见区域。最终有动画的逐帧测试、文档不变断言与页面错误检查通过，窄窗口按钮可达。
4. **P2，二维选区边框丢失，已修复。** Tailwind 的透明边框与选中颜色冲突。用 `cn` 组合互斥状态；最终二维图显示两条紫色选区边框，大纲与多选属性同步。
5. **P1，三维新主题落到屏外，已修复。** 停止自动 fit 后，空白文档连续新增会使后续主题不可点击。增加基于 Three.js 投影和 camera-controls 的选区显露，只平移，不重置缩放；连续新增、编辑、保存和键盘导航回归通过。
6. **P1，演示退出覆盖原视口，已修复。** React Flow 排队的 fit 请求可能晚于恢复执行。固定初始 fit 配置引用，并在排队取景结束后恢复视口；离屏选择、平移、缩放与文件不变断言通过。
